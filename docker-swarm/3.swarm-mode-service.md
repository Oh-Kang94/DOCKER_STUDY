# 3. 스웜 모드 서비스

## 1. 개념

기존 도커 명령어의 제어 단위는 컨테이너이다.
하지만, 스웜모드에서는 제어 단위는 컨테이너가 아닌 서비스이다.

서비스는 같은 이미지에서 생성된 컨테이너의 집합 서비스를 제어하면, 해당 서비스 내의 컨테이너에 같은 명령이 수행.
서비스 내에 컨테이너는 1개이상 존재 가능하며, 컨테이너들은 워커 노드와 메니저 노드에 할당 된다. 이러한 컨테이너들을 태스크라고 한다.

## 2. 서비스 생성

모든 명령어는 메니져 노드에서만 사용 가능

### 첫 번째 서비스 생성해보기

```bash
docker service create \
> ubuntu:22.04 \
> /bin/sh -c "while true; do echo hello world; sleep 1; done"

ndfatplmolcnxhykybnpq5vm9
overall progress: 1 out of 1 tasks
1/1: running   [==================================================>]
verify: Service ndfatplmolcnxhykybnpq5vm9 converged
```

**서비스의 컨테이너는 무조건 detached 모드로 -d 옵션을 사용해 동작 할 수 있는 이미지를 사용하여야만 한다.**

- 서비스 확인

```bash
docker service ls

ID             NAME           MODE         REPLICAS   IMAGE          PORTS
ndfatplmolcn   crazy_fermat   replicated   1/1        ubuntu:22.04
```

- 서비스 정보 확인

```bash
docker service ps crazy_fermat

ID             NAME             IMAGE          NODE             DESIRED STATE   CURRENT STATE            ERROR     PORTS
q1ovyztixr0e   crazy_fermat.1   ubuntu:22.04   lp-pc-2023-026   Running         Running 16 minutes ago
```

- 서비스 종료

```bash
docker service rm crazy_fermat

crazy_fermat
```

- 레지스트리 및 사설 레포에서 이미지를 받아 올 경우에는 메니져 노드에서 `-with-registry-auth`를 이용하면, 워커 노드에서 로그인 안해도, 사용 가능
