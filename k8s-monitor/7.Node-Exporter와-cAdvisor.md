# 7. node_exporter와 cAdvisor

## 역할 구분

| Source | 관찰 대상 | 예시 |
|---|---|---|
| node_exporter | Linux Host | CPU, Memory, Disk, Filesystem, Network |
| kubelet/cAdvisor·CRI Stats | Container·Pod | Container CPU, Working Set, Filesystem |
| kube-state-metrics | Kubernetes Object | Replica, Phase, Condition |

## node_exporter DaemonSet

```yaml
apiVersion: apps/v1
kind: DaemonSet
metadata:
  name: node-exporter
  namespace: monitoring
spec:
  selector:
    matchLabels:
      app.kubernetes.io/name: node-exporter
  template:
    metadata:
      labels:
        app.kubernetes.io/name: node-exporter
    spec:
      hostNetwork: true
      hostPID: true
      containers:
        - name: node-exporter
          image: quay.io/prometheus/node-exporter:<pinned-version>
          args:
            - --path.rootfs=/host/root
          ports:
            - name: metrics
              containerPort: 9100
          volumeMounts:
            - name: root
              mountPath: /host/root
              readOnly: true
      volumes:
        - name: root
          hostPath:
            path: /
```

Host Namespace와 Root Filesystem을 읽으므로 일반 Application보다 권한이 크다. 공식 Helm Chart·kube-prometheus의 SecurityContext와 Mount Exclusion을 기준으로 관리한다.

## Docker 설치

Docker로 Host를 관찰할 때도 Host Network·PID와 Root Bind Mount가 필요하다. Container 자신만 관찰하지 않도록 `--path.rootfs`를 맞춘다. Image `latest` 대신 Version을 고정한다.

## 확인

```bash
kubectl port-forward daemonset/node-exporter \
  -n monitoring 9100:9100
curl --fail http://127.0.0.1:9100/metrics \
  | grep node_memory_MemAvailable_bytes
```

Port Forward는 특정 Pod 하나로 연결될 수 있으므로 전체 Node Target은 Prometheus `up` Query로 확인한다.

## cAdvisor와 kubelet

Kubernetes Node에서 kubelet은 Resource Metric을 제공한다.

```text
/metrics/resource  → Metrics Server용 CPU·Memory 핵심 Metric
/metrics/cadvisor  → Container·Pod 상세 Metric
/metrics           → kubelet 자체 Process·Runtime Metric
```

독립 cAdvisor DaemonSet을 중복 배포하기 전에 Runtime과 kubelet이 이미 제공하는 Metric, 보안 Endpoint와 Prometheus Operator 구성을 확인한다.

## 대표 PromQL

```promql
100 * (
  1 - avg by (instance) (
    rate(node_cpu_seconds_total{mode=\"idle\"}[5m])
  )
)
```

```promql
sum by (namespace, pod) (
  rate(container_cpu_usage_seconds_total{
    container!=\"\",
    image!=\"\"
  }[5m])
)
```

Container Metric 이름과 Label은 Kubernetes·Runtime Upgrade에서 변경될 수 있으므로 Recording Rule로 Dashboard Contract를 안정화한다.
